# RT1 Smart Attendance
ระบบบันทึก ตรวจสอบ สรุปรายงานสถิติการมาเรียน และบันทึกครูเวรประจำวัน สำหรับโรงเรียนรวมไทยพัฒนา 1

## Features
- บันทึกการมาเรียนรายห้อง เพิ่ม/ลบ/แก้ไข/ค้นหา
- ตรวจสอบห้องที่ยังไม่บันทึก รายเดือน รายเทอม 
- ตั้งค่าภาคเรียน วันหยุด วันเรียนชดเชย
- สรุปรายงานสถิติการมาเรียนรายวัน
- บันทึกครูเวรประจำวัน
- ประวัติบันทึกครูเวร เพิ่ม/ลบ/แก้ไข/ค้นหา
- ส่งออก PDF
- ใช้งานผ่าน Google Apps Script และ Google Sheets
- ผู้ใช้ 2 ระดับ ได้แก่ แอดมิน (ผู้ดูแลระบบ) ผู้ใช้ทั่วไป (ครูผู้บันทึก)
